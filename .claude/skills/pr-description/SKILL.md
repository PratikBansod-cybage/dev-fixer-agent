# Pull request description

Use exactly these sections, in this order:

## Summary
One sentence: what the PR changes.

## Root cause
What was wrong and why.

## Change
Bullet list: `file:line` - what changed.

## Tests
The command you ran and its result line, plus any test you added.

## Ticket
`Jira: <KEY>` and `Fixes #<issue number>` if a GitHub issue exists.
